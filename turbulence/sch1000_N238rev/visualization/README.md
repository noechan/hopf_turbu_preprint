# Visualization: canonical N145 harmonized rerun

Active scripts reproduce the harmonized N145 manuscript analyses. Turbulence
inputs come from `harmonization_allfeat/recomputed/`; the AT(N) regression
stage additionally reads mounted biomarker sources without copying them into
the repository. Outputs are isolated under:

```text
figures_N145/
└── sch1000/Abeta_Status/harmonized_allfeat/
    ├── global/              global MATLAB figures and FDR results
    ├── nodewise_stats/      historical node-wise MAT/XLSX files
    ├── RSN_top30_FDR_age_sex_education/
    │                        covariate-adjusted Figure 3 Yeo-7 summaries
    ├── rendering_adjP/      Figure 3 -log10(adjusted p) surface maps
    └── python/              global, radar, and AT(N) regression figures
```

The group order is `HC-`, `HC+`, `MCI+`, `AD+`, with respective sample sizes
51, 37, 31, and 26 (N=145). Global and node-wise permutation analyses use
fixed random seed 1.

## Manuscript node-level method

Figure 3 is restricted to turbulence at lambda=0.01 and two contrasts:

1. HC Aβ- versus AD Aβ+
2. MCI Aβ+ versus AD Aβ+

The manuscript inference is generated by
`statistical_analysis/nodewise_metastability/run_nodewise_metastability_N145_age_sex_education.R`.
It performs two-sided Freedman--Lane permutation tests at each of the 1,000
Schaefer parcels while adjusting for age, sex, and education, and applies
Benjamini--Hochberg FDR across parcels separately within each contrast. See
`MANUSCRIPT_NODE_LEVEL.md` for the audit trail.
The physical scale is explicit in every active filename: `lambda_0_01` is
MATLAB array index 10. The historical name `lam1` encodes physical
lambda=0.01 (and similarly `lam3`=0.03 and `lam6`=0.06), but explicit
physical-value filenames are required for the active rerun.

The surface maps display the complete `-log10(P_FDR_BH)` vector. Radar plots use
the parcels at or below the 30th percentile of `P_FDR_BH`, retain threshold ties,
and count them across Yeo-7 networks in manuscript order:
`VIS, SM, DAT, VAT, LIM, CNT, DMN`.

## Run order

Start MATLAB in `sch1000_N238rev`:

```matlab
setup_sch1000_paths;

% 1. Global Figure 3-style harmonized results
h_plot_turbubyAbeta_N238rev_perm_HC_MCI_AD_ABetaStaging

% Figure 3 cortical maps
render_turbu_node_HC_AD_ADNI3_sch1000_abetastaging_combat_adjp
render_turbu_node_MCI_AD_ADNI3_sch1000_abetastaging_combat_adjp
```

The cortical renderer needs only the `gifti` reader from the SPM12 root
folder; it does not require starting the SPM application or adding all SPM
subfolders. If `gifti` is not already available, use:

```matlab
addpath('/path/to/spm12')
```

The historical unused `ft_read_cifti` call has been removed, so FieldTrip is
not required for these Schaefer-1000 Figure 4 maps.

Run Python global figures from the repository root with:

```bash
.venv-turbulence/bin/python \
  turbulence/sch1000_N238rev/visualization/python/run_harmonized_visualizations.py \
  --stage global
```

After running the education-adjusted R node-wise analysis, use `--stage radar`
to regenerate the two manuscript lower-30% Yeo-7 radar plots plus an
atlas-size-normalised representation figure:

```bash
.venv-turbulence/bin/python \
  turbulence/sch1000_N238rev/visualization/python/run_harmonized_visualizations.py \
  --stage radar
```

The historical single-contrast radar entry points now delegate to this
canonical workflow and no longer read the superseded `permFDR.xlsx` files.

Use `--stage atn` to rerun both AT(N) statistical specifications and rebuild
Figure 4 c, d, j, k, and l. The statistical stage fits age/sex and
age/sex/education models, saves aggregate results under
`statistical_analysis/atn_biomarkers/results/N145_atn_regressions/`, and does
not save participant-level merged data. The plotting stage then reads those
saved results without refitting and writes separate PDF/PNG sets under
`python/atn_regressions/age_sex/` and
`python/atn_regressions/age_sex_education/`. See
`ATN_REGRESSION_PROVENANCE.md` for the exact inputs and models.

Use `--stage all` to run global, radar, and AT(N) Python stages together.

Historical node renders, raw diagnosis-matrix scripts, and archived result
files are omitted from the publication repository.
