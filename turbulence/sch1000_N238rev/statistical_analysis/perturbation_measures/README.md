# N145 subject-level perturbation measures

This folder contains the active statistical analyses of participant-level
information capacity (`Info_Cap`) and susceptibility. These measures come from
the subject-specific Hopf perturbation simulations and are distinct from the
empirical fMRI information-flow, information-transfer, and information-cascade
measures analysed in `turbu_harm_stats/`.

## Input provenance

The two Hopf measures and amyloid-status group are read from:

```text
data_export/ML_Input_ADNI3_4STAGINGBYABETA_ComBat_N145_with_infocap_suscep_sch1000.csv
```

That file is generated by
`data_export/data_for_ML_4Staging_with_InfoCap_Susceptibility.m`, which aligns
the participant-level Hopf table to the current N145 dynamics cohort by PTID.

Age, sex, and years of education are always joined by PTID from the local copy
of the canonical ComBat metadata:

```text
$SCH1000_ROOT/data/covariates/covariates_ADNI3_ABeta_N152.csv
```

MOCA is joined by PTID from the active local N145 clinical table. Its duplicate
dynamical and demographic fields are not used by these analyses.

## Education-adjusted group comparisons

`run_subjectlevel_perturbation_group_N145.R` fits, separately for information
capacity and susceptibility:

```text
Outcome ~ Group + Age + Sex + Education
```

The four-level omnibus effect and the five planned manuscript contrasts use
Freedman--Lane residual permutation with 100,000 permutations. Omnibus
p-values are BH-FDR corrected across the two outcomes. Pairwise p-values are
BH-FDR corrected across the five planned stage comparisons separately within
each outcome. Adjusted Hedges' g is reported as Group 1 minus Group 2.

Validate and run from the publication repository's `turbulence/` directory:

```bash
Rscript \
  sch1000_N238rev/statistical_analysis/perturbation_measures/run_subjectlevel_perturbation_group_N145.R \
  --validate-only

Rscript \
  sch1000_N238rev/statistical_analysis/perturbation_measures/run_subjectlevel_perturbation_group_N145.R
```

For a technical smoke test, add `--n-perm 100`. Aggregate outputs are written
to `results/N145_subjectlevel_perturbation/`.

## MOCA multiple linear regressions

`run_moca_subjectlevel_perturbation_N145.py` tests information capacity and
susceptibility in separate regressions. Separate models avoid making either
coefficient conditional on the other measure. Predictors are standardized, so beta is the expected change in
raw MOCA points per one-SD increase in the corresponding measure.

In the current N145 Hopf input, the two measures are almost perfectly
correlated (`r = 0.9996`). They are therefore not entered together in a joint
model: their predictor-specific coefficients would be unstable and could not
support a meaningful comparison of independent contributions. The correlation
is recorded in both run outputs for traceability.

Two specifications are reported:

```text
Total association:
MOCA ~ z(measure) + Age + Sex + Education

Association beyond disease stage:
MOCA ~ z(measure) + Age + Sex + Education + Group
```

The second is a sensitivity estimand rather than a preferred replacement for
the first: amyloid-status group may lie on the disease pathway. Coefficient
inference uses HC3 heteroscedasticity-consistent standard errors. BH-FDR is
applied across the two predictors separately within each specification.
Full-model R-squared, incremental R-squared beyond the covariate-only model,
partial R-squared, confidence intervals, and predictor VIF are saved.

Run with the repository virtual environment:

```bash
.venv/bin/python \
  sch1000_N238rev/statistical_analysis/perturbation_measures/run_moca_subjectlevel_perturbation_N145.py \
  --validate-only

.venv/bin/python \
  sch1000_N238rev/statistical_analysis/perturbation_measures/run_moca_subjectlevel_perturbation_N145.py
```

Use `--model-set total` or `--model-set group-adjusted` to run only one
specification. Aggregate outputs are written to
`results/N145_MOCA_subjectlevel_perturbation/`; participant-level merged data
are never written.

Use `--metadata-file` to override the local covariate copy explicitly.

## AT(N) biomarker regressions

`run_atn_subjectlevel_perturbation_N145.py` tests whether participant-level
information capacity and susceptibility are associated with the same five
prespecified AT(N) outcomes used by the active turbulence analysis: amyloid
burden, bilateral hippocampal grey-matter volume, and mesial, metatemporal,
and temporoparietal tau. Each predictor is fitted separately as:

```text
AT(N) outcome ~ z(measure) + Age + Sex + Education
```

Separate models are required because information capacity and susceptibility
are nearly perfectly correlated in the current export (`r = 0.9996`). HC3
robust inference is used, and BH-FDR is applied across the five AT(N) outcomes
separately within each predictor. Standardized predictor coefficients, raw-
unit coefficients, incremental and partial R-squared, prediction lines, and
provenance are saved; participant-level merged data are not written.

```bash
.venv/bin/python \
  sch1000_N238rev/statistical_analysis/perturbation_measures/run_atn_subjectlevel_perturbation_N145.py \
  --validate-only

.venv/bin/python \
  sch1000_N238rev/statistical_analysis/perturbation_measures/run_atn_subjectlevel_perturbation_N145.py
```

Aggregate outputs are written to
`results/N145_ATN_subjectlevel_perturbation/`. The AT(N) outcomes remain in
the mounted ADNI source tables by default; use `--tau-file` and `--vbm-file`
to override their locations.

The corresponding education-adjusted PDF and PNG regression plots can be
generated from the saved coefficients and prediction lines without refitting
the models:

```bash
.venv/bin/python \
  sch1000_N238rev/visualization/python/scripts/plot_atn_subjectlevel_perturbation.py
```

Alternatively, rebuild the analysis and all ten plots together with:

```bash
.venv/bin/python \
  sch1000_N238rev/visualization/python/run_harmonized_visualizations.py \
  --stage subject-atn
```

Figures are written to
`figures_N145/sch1000/Abeta_Status/harmonized_allfeat/python/atn_regressions/subjectlevel_age_sex_education/`.
The analysis prefers the corresponding tau and VBM source tables already in
the local `HPC_Hopf_SUB_DTI_1000_Staging/visualization/data/` repository and
falls back to the mounted ADNI copy when the local directory is unavailable.

## Current education-adjusted results

The canonical 100,000-permutation group analysis found no significant omnibus
stage effect for information capacity (`pFDR = 0.1001`) or susceptibility
(`pFDR = 0.1001`). None of the five planned pairwise comparisons survived FDR
correction within either outcome. The largest adjusted pairwise effects were
HC Aβ- versus AD Aβ+ (`g = 0.527` for both measures), but their raw permutation
p-values were approximately `0.058` and their adjusted p-values were `0.165`
and `0.184`.

The MOCA analysis used 144 participants because one HC Aβ+ participant has no
MOCA score. Neither measure was significantly associated with MOCA after adjustment
for age, sex, and education. Information capacity gave `beta = 0.438` MOCA
points per predictor SD (`pFDR = 0.168`), and susceptibility gave
`beta = 0.440` (`pFDR = 0.168`). After additionally adjusting for amyloid-status
group, both coefficients were close to zero and non-significant
(`pFDR = 0.656`).

For the AT(N) analysis, greater information capacity and susceptibility were
each associated with lower amyloid burden and lower mesial, metatemporal, and
temporoparietal tau after adjustment for age, sex, and education; all four
associations survived FDR correction within each measure (`pFDR = 0.0112`--
`0.0362`). The positive associations with bilateral hippocampal volume did not
survive FDR correction (`pFDR = 0.115` for information capacity and `0.108` for
susceptibility). Amyloid and hippocampal models used N=145; tau models used
N=134.
