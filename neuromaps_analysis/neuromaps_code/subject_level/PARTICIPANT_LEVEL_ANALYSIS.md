# Participant-level E:I--turbulence analysis

This document explains the analysis in the order in which it is performed.
The executable runner is
`run_subjectlevel_ei_turbulence_coupling.py`; the detailed calculations are
split into the `ei_subjectlevel/` modules listed below.

## Scientific question

For each participant, how closely does the spatial distribution of turbulence
at physical lambda = 0.01 follow the normative cortical E:I expression map?
Does this correspondence progressively decrease across the ordered groups
HC amyloid-negative, HC amyloid-positive, MCI amyloid-positive, and AD
amyloid-positive?

## Analysis flow

```text
Harmonized N145 parcel maps + normative E:I map
                         |
                         v
             Common left cortical surface
                         |
                         v
        Participant r, Fisher z, and spin z
                         |
                         v
       Covariate-adjusted trend and contrasts
                         |
                         v
         Tables, figure, and provenance JSON
```

### 1. Load already harmonized participant maps

The input is the canonical ComBat-harmonized N145 table generated by
`turbulence/sch1000_N238rev/harmonization_allfeat/run_harmonization.py`.
The participant analysis does **not** fit ComBat again.

Each row is one participant and each `Schaefer_1` to `Schaefer_1000` column is
that participant's turbulence value in one cortical parcel. Before analysis,
the code checks:

- the expected group sizes (51, 37, 31, and 26);
- exact agreement with the manuscript N145 PTID and group table;
- 1,000 ordered, finite Schaefer values; and
- reproduction of the retained HC-minus-AD mean map.

### 2. Put E:I and turbulence in the same cortical space

Each participant's Schaefer-1000 volume and the normative E:I volume are
projected to the fsaverage 41k surface. Statistical calculations retain only
the left hemisphere because the primary paper-style transcriptomic estimate
uses the 500 left-hemisphere parcels.

The correlation is calculated over valid left-hemisphere surface vertices.
Consequently, parcels contribute in proportion to their represented surface
vertices rather than each parcel receiving exactly equal weight.

### 3. Calculate one spatial coupling value per participant

For participant *i*, the empirical Pearson correlation is

```text
r_i = corr(turbulence_i(v), EI(v))
```

where *v* indexes the jointly valid left-hemisphere vertices. A high positive
value means that regions with relatively high normative E:I also tend to have
relatively high turbulence for that participant.

The primary regression outcome is the Fisher transformation

```text
fisher_z_i = arctanh(r_i)
```

which places correlations on a scale more suitable for linear modelling.

As a spatial-autocorrelation sensitivity analysis, the E:I surface is rotated
1,000 times using shared Alexander--Bloch rotations. Each participant is
correlated with every rotated E:I map, producing a participant-specific null
distribution. The spatially normalized score is

```text
spin_z_i = (r_i - mean(null_r_i)) / sd(null_r_i)
```

The same rotations are used for all participants, so their normalized scores
are based on the same spatial null configurations.

### 4. Test progression across groups

The confirmatory ordered-stage model codes the groups as 0, 1, 2, and 3:

```text
coupling_i = intercept + beta_stage * stage_i
             + beta_age * age_i + beta_gender * gender_i
             + beta_education * education_i + error_i
```

A negative `beta_stage` supports a progressive reduction in correspondence
with the normative E:I architecture. Age and education are standardized;
gender is included as supplied in the demographic table.

The coefficient is accompanied by HC3 robust standard errors. Permutation
inference uses the Freedman--Lane procedure: residuals from the reduced model
without the tested group/stage term are permuted, while the covariate effects
are retained. Group labels themselves are not simply shuffled.

Three planned categorical comparisons use HC amyloid-negative as the
reference:

- HC amyloid-positive versus HC amyloid-negative;
- MCI amyloid-positive versus HC amyloid-negative; and
- AD amyloid-positive versus HC amyloid-negative.

Their two-sided permutation p-values are corrected together using BH-FDR,
separately for each outcome. The analysis is run first for `fisher_z` and then
for `spin_z` as the spatially normalized sensitivity outcome.

### 5. Save auditable outputs

The workflow saves participant coupling values, group descriptives, ordered
trend tests, planned comparisons, the figure, and JSON provenance containing
input paths and checksums.

## Where each calculation lives

| File | Purpose |
| --- | --- |
| `run_subjectlevel_ei_turbulence_coupling.py` | Short, numbered analysis workflow |
| `ei_subjectlevel/inputs.py` | Load data and validate cohort/provenance |
| `ei_subjectlevel/spatial.py` | Surface projection, Pearson r, Fisher z, and spin nulls |
| `ei_subjectlevel/statistics.py` | HC3 regression, Freedman--Lane inference, contrasts, and descriptives |
| `ei_subjectlevel/plotting.py` | Publication boxplots |
| `ei_subjectlevel/outputs.py` | Tables and reproducibility metadata |

## Running the workflow

Validate inputs only:

```bash
.venv-neuromaps/bin/python \
  neuromaps_analysis/neuromaps_code/subject_level/\
run_subjectlevel_ei_turbulence_coupling.py --validate-inputs-only
```

Run the complete confirmatory analysis:

```bash
.venv-neuromaps/bin/python \
  neuromaps_analysis/neuromaps_code/subject_level/\
run_subjectlevel_ei_turbulence_coupling.py
```
